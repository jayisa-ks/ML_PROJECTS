### Flight Price Analysis and Prediction using Machine Learning

### Overview

Analyzed flight ticket pricing data and built machine learning models to predict airfare costs. The project examines factors such as airline, route, travel class, duration, number of stops, and days left before departure to understand price variations.

### Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

### Models Used

* Linear Regression
* Polynomial Regression

### Key Insights

* Flight prices vary significantly by airline, route, and travel class.
* Ticket prices tend to increase as the departure date approaches.
* Polynomial Regression achieved better prediction accuracy than Linear Regression.
